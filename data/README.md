# Data inputs

The figure and table programs use intermediate Stata datasets containing
country and subgroup estimates, standard errors, confidence intervals, and
survey summary statistics.

The input directory structure is:

- `data/graphs and tables/`: intermediate inputs for the final figures and tables;
- `data/wbdata.dta`: matched World Development Indicators used in Figures 1a
  and S2;
- `data/aux data/World Bank Official Boundaries - Admin 0/`: geographic inputs
  used in Figure S1.
